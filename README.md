# RFCM OpenLP Wi-Fi Remote

### Free Wi-Fi Remote Control for OpenLP — Windows & Linux

**Developed by Reconcilers For Christ Ministries (RFCM)**

RFCM OpenLP Wi-Fi Remote is a FREE companion application that lets you control OpenLP from your smartphone over a local Wi-Fi network.

Designed for churches, worship teams, ministries, and presentation operators, RFCM Remote provides convenient control without needing to stand at the presentation computer.

**Version 8.4.0 — Windows & Linux**

## Features

- **Wireless control:** Use your Android phone, iPhone, or other device with a modern web browser.
- **NEXT / PREVIOUS:** Navigate through your OpenLP service.
- **Play, Pause, and Stop:** Control video playback remotely.
- **Automatic Video Advance:** Optionally advance to the next service item approximately three seconds before a timed video finishes. Ordinary slides do not advance automatically.
- **Volume Control:** Adjustable volume, including extended volume capability where supported.
- **Eight Custom Themes:** Choose your preferred remote appearance.
- **PIN Protection:** Help prevent unauthorized remote access.
- **Local Wi-Fi Operation:** No internet connection required during normal operation.
- **Simple Phone Connection:** Connect using the address or QR code provided by the launcher.
- **Free Software:** No purchase required. Optional donations are appreciated.

## Requirements

- A compatible installation of OpenLP with its remote API enabled.
- A Windows or supported Linux computer running RFCM Remote.
- A smartphone or tablet connected to the same local network.
- A web browser on the controlling device.

**RFCM Remote does not require modifications to OpenLP.**
